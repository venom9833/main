## 2. polystyle — 로우폴리 (확정, 기본값)

### 스타일 정의
```
low-poly hard polygon mesh + 3등신 캐릭터 비례 + 6색 고정 팔레트
```

### 6색 고정 팔레트
| 역할 | 색명 | HEX |
|------|------|-----|
| 그림자·배경 | deep black | `#111118` |
| 가구·창틀·의상 베이스 | dark navy | `#1A2840` |
| 포인트 의상·강조 | bright blue | `#4A90D9` |
| 형광등·흰 의상 | white | `#F5F5F5` |
| 피부 | natural skin | `#D4BEA0` |
| 감정 오브젝트 (1개 한정) | crimson red | `#C0392B` |

### 핵심 원칙
- crimson red는 **씬별 배경 오브젝트 1개에만** — 캐릭터에 사용 금지
- 6색 팔레트 외 색 사용 절대 금지 → Negative에 `extra colors outside palette` 필수
- `photorealistic`, `smooth shading`, `gradients` 혼용 금지
- 캐릭터는 3등신 비례 강제 (`3-head proportion` 명시)
- 캐릭터 레퍼런스 이미지는 크로마키 그린 `#00B140` 배경으로 생성 (합성 자동화용)

### base_style_prompt
```
low-poly hard polygon mesh illustration, all surfaces flat facets no gradients no blending,
six-color palette only deep black #111118 dark navy #1A2840 bright blue #4A90D9
white #F5F5F5 natural skin #D4BEA0 crimson red #C0392B accent only,
hard geometric shadow edges, 3-head proportion chibi-style characters,
Korean drama cinematic framing, no text no written words no letters no labels no signs no captions
```

### Negative 프롬프트
```
photorealistic, smooth shading, gradients, blending, soft shadows,
oil painting, watercolor, anime, extra colors outside palette,
realistic body proportions, 7-head proportion, 8-head proportion,
long neck, elongated body, deformed, extra limbs, text, watermark
```

### 배경 팔레트 (7색 — 캐릭터 팔레트와 분리)
| 역할 | 색명 | HEX |
|------|------|-----|
| 가장 어두운 그림자·배경 심도 | near-black | `#180A20` |
| 주 그림자·공간 깊이 | dark purple | `#462374` |
| 중간 그림자·벽·바닥 | deep mauve | `#7D2E67` |
| 중간 톤·조명 | medium purple | `#B752B8` |
| 밝은 포인트·강조 | orchid pink | `#D67DD1` |
| 반사광·하이라이트 | lavender | `#AC8AE1` |
| 최고 밝기·창·조명 | silver-white | `#DDDDDD` |

### 캐릭터 레퍼런스 파일 구조
```
캐릭터 스타일 JSON:  apps/api/data/characters/{char_id}_polystyle.json
레퍼런스 이미지:     (R2 저장, reference_url 필드)
프롬프트 레퍼런스:   docs/rules/65_V3_폴리스타일_캐릭터_레퍼런스.md
```

## 4. 신규 화풍 추가 방법

향후 새 화풍이 필요할 때 아래 3단계로 추가한다. 기존 polystyle 코드를 수정하지 않아도 된다.

### Step 1 — `art_styles.json`에 화풍 키 추가
```json
{
  "new_style_key": {
    "label": "화풍 이름",
    "description": "설명",
    "base_style_prompt": "...",
    "negative_prompt": "...",
    "bg_prompt_suffix": "...",
    "pillow_palette": [[r, g, b], [r, g, b]],
    "pillow_accent": [r, g, b]
  }
}
```

### Step 2 — 캐릭터 스타일 JSON 추가
```
apps/api/data/characters/{char_id}_{new_style_key}.json
  → reference_url: "R2에 업로드한 레퍼런스 이미지 URL"
```

### Step 3 — 시리즈 settings 지정
```json
{ "artStyle": "new_style_key" }
```

> **코드 변경 불필요**: `_resolve_portraits()`, `prompt_composer.py`, `get_art_style_config()` 등
> 모두 `art_styles.json` 키를 동적으로 읽으므로 JSON 추가만으로 즉시 동작한다.
