## 2. 캐스팅 엔진 — 결정론적 트롭 기반 (AI 0회)

- `_index.json`에 등록된 캐릭터 풀에서 트롭 태그 매칭으로 선발

## 3. 등록 캐릭터 vs 미등록 캐릭터

### 등록 캐릭터 (주연급)
- `_index.json`에 등록
- 전용 캐릭터 JSON 파일 존재 (`{id}.json`, `{id}_masako.json`, `{id}_noir_oil.json`)
- `prompt_composer.py`가 외모·의상 정보를 파일에서 직접 로드

### 미등록 캐릭터 (조연급)
- Gemini 대본 생성 시 자유 창작 (예: 전처 송현아, 현장 동료 등)
- `_index.json`에 없음 → 외모 정보 없음
- **대본 Gemini의 자유 창작 제한하지 않는다** — 제한 시 대본 품질 저하 확인

## 4. 조연 처리 전략 — 확정 (2026-04-13)

### 원칙

> **대본 Gemini는 "누가 나오는가"만 안다. "어떻게 생겼는가"는 SCRIPT 후처리가 담당한다.**

### 처리 불가 위치

| 위치 | 이유 |
|------|------|
| CASTING | 미등록 조연가 아직 창작되지 않은 시점 |
| ARCHITECT | SCRIPT 이전 실행 — 조연 이름 자체가 없음 |
| 대본 Gemini | 대본 품질에 집중해야 함, 외모 부담 주지 않음 |

### 처리 위치 — SCRIPT 완료 직후 자동 후처리

```
SCRIPT 완료
    ↓
[POST-SCRIPT 자동]
  1. scene_meta.characters 전체 스캔
  2. _index.json에 없는 이름 추출
  3. 등장 씬의 image_hint + text로 컨텍스트 수집
  4. 경량 Gemini 호출 (외모만, 대본과 무관)
     입력: 이름, 나이대, 관계, 등장 씬 요약
     출력: fal_identity_prompt + wardrobe_default/casual/stressed
  5. world_data.guest_cast 저장
    ↓
AWAITING_SCRIPT_APPROVAL (기존 게이트, 변경 없음)
```

### prompt_composer.py fallback 순서

```
글로벌 _index.json  →  world_data.guest_cast  →  이름만 텍스트 삽입
```
