## 1. Poly Style 정의

### 화풍 key
`polystyle`

### 특징

| 항목 | 내용 |
|------|------|
| 렌더링 | low-poly hard polygon mesh — 모든 면이 flat facet, 그라데이션·블렌딩 없음 |
| 비율 | 3-head proportion — 총 키의 1/3이 머리 (3등신) |
| 팔레트 | 6색 고정 hex |
| 조명 | 하드 섀도우, 형광등/도시야경 역광 |
| 포인트 | crimson red = 씬별 오브젝트 1개에만 |

### 6색 고정 팔레트

| 역할 | 색명 | HEX |
|------|------|-----|
| 그림자·배경 | deep black | `#111118` |
| 가구·창틀·의상 베이스 | dark navy | `#1A2840` |
| 포인트 의상·강조 | bright blue | `#4A90D9` |
| 형광등·흰 의상 | white | `#F5F5F5` |
| 피부 | natural skin | `#D4BEA0` |
| 감정 오브젝트 (1개 한정) | crimson red | `#C0392B` |


## 3. 프롬프트 작성 원칙

### 의상 고유화
- 캐릭터별 고유 실루엣 필수 — 비슷한 복장 금지
- 색 배분이 달라야 함 (흰색 위주 vs 네이비 위주 vs 블랙 위주)
- 직업·연령·성격이 의상에 반영되어야 함

### 얼굴 특이 마킹 전면 제외 (2026-04-17 확정)
점·사마귀·흉터·birthmark 등 **일체 제외** — AI 생성 시 등장 여부가 불일치하여 캐릭터 일관성을 깨뜨림.
얼굴 묘사는 **형태·피부톤·눈코입 구조**만 사용.
