## 이미지 마스터번호 규칙 ★

### 포맷

```
IP{4자리 제로패딩 순번}.jpg
예: IP0001.jpg, IP0002.jpg, ... IP0869.jpg
```

### 부여 방식

1. `ours=true` 프롬프트 목록을 `id` 기준 알파벳 정렬 (안정적 재현성 보장)
2. 정렬 순서대로 1번부터 `IP{N:04d}` 부여
3. `index_img.json` 각 항목에 `master_no` 필드 저장
4. 로컬 저장: `D:\img_prompt\thumbs\IP{N:04d}.jpg`
5. R2 업로드: `img-prompts/thumbs/IP{N:04d}.jpg`

### 안정성

- 동일 입력 데이터 → 동일 마스터번호 (id 정렬 기준)
- prompts3.com 신규 항목 추가돼도 기존 번호 불변 (기존 id 정렬 순서 유지)
- `master_no`는 영구 식별자 — R2 경로·UI URL·로그에서 일관되게 사용

## 데이터 흐름

```
[일회성 수집]
prompts3.com/data/prompts.json
    │ requests.get → ours=true 필터(869건) → id 정렬
    ▼
img_prompt_collector.py
    ├── 마스터번호 부여 (IP0001~IP0869)
    ├── index_img.json 생성 → D:\img_prompt\index_img.json
    └── 썸네일 다운로드 → D:\img_prompt\thumbs\IP{N:04d}.jpg (리네임)

[일회성 업로드]
img_prompt_r2_upload.py
    └── D:\img_prompt\ → R2 linkdrop-assets/img-prompts/
        ├── index_img.json
        └── thumbs/IP0001.jpg ~ IP0869.jpg

[런타임]
FastAPI startup
    ├── local: D:\img_prompt\index_img.json 읽기 → 메모리 캐시
    └── r2: R2_ASSETS_PUBLIC_URL/img-prompts/index_img.json fetch → 메모리 캐시

프론트
    └── /api/v1/img-prompts → 카드 그리드 → 모달 → /generate
```

## 수집 스크립트 설계 (`img_prompt_collector.py`)

핵심 로직 (의사코드):

```python
prompts = fetch_and_filter_ours(url)   # ours=True만
prompts.sort(key=lambda p: p["id"])   # id 알파벳 정렬

for n, p in enumerate(prompts, start=1):
    master_no = f"IP{n:04d}"
    p["master_no"] = master_no
    p["thumb"] = f"thumbs/{master_no}.jpg"
    download_thumb(original_thumb_url, f"D:\\img_prompt\\thumbs\\{master_no}.jpg")

write_json("D:\\img_prompt\\index_img.json", {...})
```

보조 검증:
- `len(prompts)` 가 860~880 범위 벗어나면 경고 (구조 변경 감지)
- 썸네일 다운로드 실패 시 항목별 로그, 전체 중단 없음

## R2 업로드 스크립트 설계 (`img_prompt_r2_upload.py`)

- boto3 S3 호환 클라이언트 (endpoint_url = R2_ENDPOINT, region_name="auto")
- `--force` 없으면 HEAD 200인 키 skip (멱등)
- `index_img.json` → CacheControl `public, max-age=300`
- `thumbs/IP*.jpg` → CacheControl `public, max-age=2592000` (30일, 불변)

---

## FastAPI 캐시 설계 (`img_prompt_cache.py`)

- `IMG_PROMPT_SOURCE` env: `local` (기본) / `r2`
- 모듈 전역 `_INDEX = None` — 첫 호출 시 1회 로드
- `filter_prompts(cat, search, featured, page, page_size)` — 869건 메모리 필터
- `thumb_url` 조립: `{BASE_URL}/img-prompts/{thumb}` (BASE_URL = localhost:8001/img-prompts-static or R2)
- 검색: `search.lower()` in `title+description+content` 합산 문자열

## LLM 폴백 (LD-011/012 준수)

```python
# 🟢 CEREBRAS-FREE
try cerebras → return

# ✅ GEMINI-FREE
except → try gemini_free → return

# ⚠️ GEMINI-PAID: GOOGLE_API_KEY 유료 과금 (이미지 프롬프트 refine 폴백)
except → try gemini_paid → return

except → raise HTTPException(503)
```

시스템 프롬프트: "이미지 생성 프롬프트를 더 구체적이고 시각적으로 풍부하게 다듬어라. 한국어 입력은 한국어로 응답. `{argument...}` 변수 토큰 보존."

## 프론트 컴포넌트 구조

```
page.tsx (Tab 타입에 'image' 추가)
└── activeTab === 'image' → <PromptTabImage />
    ├── 사이드바: 카테고리 칩(전체+869, 카테고리별 count) + 검색창 + featured 토글
    ├── 그리드: ImagePromptCard × 60 (4열→2열→1열 반응형)
    │   └── 썸네일(lazy) + 제목 + 카테고리 배지 + master_no 라벨
    ├── 페이지네이션: [이전] page/total [다음]
    └── ImagePromptModal (selected 카드)
        ├── 썸네일 + 메타 (제목/설명/master_no/카테고리)
        ├── Args 입력 폼 (default 값 자동 채움)
        ├── compilePrompt() 결과 <pre> (실시간 갱신)
        ├── [복사] [ChatGPT 바로 실행 (window.open)]
        └── AI Studio: [AI로 다듬기] → POST /generate → 결과 + 모델 라벨
```

`compilePrompt.ts`:
- 정규식: `/\{argument\s+name="([^"]+)"\s+default="([^"]*)"\}/g`
- args 정의 라인 제거 + values 치환
- `extractDefaults(args)` 헬퍼 → 모달 초기값
