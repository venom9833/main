"GNB 메뉴 중메뉴 수정" 요청 시 **기존 상위 메뉴 항목을 절대 삭제하지 말 것**.

**Why:** "중메뉴 4개만 나오도록"이라는 지시를 전체 메뉴 교체로 잘못 해석하여 서비스소개/AI클래스/영상자동화 등 기존 항목을 모두 지웠다가 사용자가 화를 냄.

**How to apply:**
- "중메뉴" = navItems.ts의 children 배열 (드롭다운 하위 항목)
- "상위 메뉴" = NAV_ITEMS 최상위 배열 (서비스소개, 웹소설, 영상자동화 등)
- 중메뉴 수정 = children href/label만 변경, NAV_ITEMS 구조는 절대 건드리지 않음
