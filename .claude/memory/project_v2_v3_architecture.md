## V2 = 소비자 접점 (프론트 레이어)

- 9개 니즈별 랜딩 페이지 (소비자가 직접 만나는 화면)
- ₩59,000 전자책 결제 / 파트너 마이페이지 / 수당 대시보드
- 강사 양성 과정 등록 / CRM

## V3 = 웹소설+영상 자동화 전용 엔진 (2026-04-22 확정)

- **담당 범위**: 소스 인제스트 → 세계관 → 대본 → 키프레임 → TTS → 렌더 → 업로드
- **그 외 전부(랜딩·결제·CRM·수당·파트너·강사)는 V2에서 처리** — V3에 마케팅/CRM 추가 금지
- V3 프론트(`apps/web`)도 웹소설+영상 자동화 UI만 담당 (studio 기능)

## 역할 분리

| 구분 | V2 | V3 |
|------|----|----|
| 역할 | 판다 | 만든다 |
| 사용자 | 소비자·파트너·강사 | AI 에이전트 |
| 관심사 | 결제·수당·CRM·UX | 대본·영상·자동화 품질 |

**Why:** V2가 "무엇을 팔지"를 결정하고, V3는 "그 약속을 이행"한다.  
마케팅(V2)과 기술(V3)이 서로 간섭 없이 독립적으로 발전 가능.

**How to apply:** V3 작업 시 소비자 UX·결제·수당은 V2 영역임을 인식. V3는 콘텐츠 생산 품질과 자동화에만 집중.
