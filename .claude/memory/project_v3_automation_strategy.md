V3는 초기에 사용자 개입(게이트)을 유지하고, 결과물 품질이 표준화되면 게이트를 하나씩 제거하는 단계적 자동화 전략을 따른다.

**현재 게이트 (개입 있음):**
1. 세계관 편집 + 화풍 선택 + 캐릭터 수정
2. 대본 승인
3. 키프레임 방식 선택 (NLM/API)
4. 씬별 이미지 선택
5. 최종 영상 확인 + 업로드 승인

**Why:** 품질 기준이 확립되기 전까지 사람이 검수. 결과물이 일정 수준으로 수렴하면 해당 게이트를 자동으로 전환.

**How to apply:**
- 각 게이트는 반드시 설정값(config/DB)으로 on/off 가능하게 설계할 것
- 코드 수정 없이 게이트 비활성화 가능해야 함 (series.settings.autoApprove 등)
- 게이트 제거 순서는 사용자가 결정 — 코드에 순서를 강제하지 말 것
- 게이트별 승인 이력을 DB에 기록 → 품질 데이터로 활용 가능하게
