# HOOK 컷 2회 등장 = 설계 의도 (53번 문서 확정)

**Why:** 영상 맨 앞에 시청자를 낚는 콜드오픈(cold open)을 자동 삽입하기 위한 설계. `_parse_scenes_json()`이 HOOK 컷을 감지하면 자동으로 scene_index=0 복사본을 생성하고, 원본은 서사 흐름 위치에 그대로 유지된다.

**How to apply:** v3_scenes에서 동일 마스터코드를 가진 컷이 2개 발견되어도 절대 삭제하거나 중복 버그로 분류하지 말 것.

```
재생순서  scene_index  마스터코드     설명
[1]        0        ch01s00hc01  ← HOOK 복사본 (콜드오픈, 자동 생성)
[2]        1        ch01s01nc01  ← 대본 처음부터
...
[N]        4        ch01s04hc01  ← HOOK 원본 (서사 흐름 속 자연 위치)
```

이전 세션에서 이를 "버그"로 오평가한 후 사용자 지적으로 수정됨.
