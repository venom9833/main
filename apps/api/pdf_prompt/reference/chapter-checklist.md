## Step 5: 리라이팅 체크리스트 (10항목)

10항목을 위에서 아래로 순서대로 적용한다.

|#|점검 항목|기준|
|-|-|-|
|1|종결어미 일관성|Phase 1 확정 어미 이탈 0건|
|2|문장 길이|30\~60자 기본. 15자 이내 단문이 문단당 최소 1회 (리듬 끊기)|
|3|문단 호흡|2\~4문장 기본. 문단 초반은 장면/상황, 후반은 판단 밀도 상승 (점층 구조)|
|4|금지어 제거|과장 형용사, 모호 부사, 교훈 강요, 감정 유도 표현 0건|
|5|반복 표현 정리|동일 접속사("그런데", "하지만", "그래서") 전체 원고에서 각 2회 이내. 동일 문장 구조 3회 연속 반복 금지|
|6|어휘 전환|감정형 표현 → 상태 진단형. 추상 명사 중심 → 동사 중심 문장|
|7|리듬 변화|중문(40자 이상)만 이어지는 구간이 3문장을 넘지 않도록 단문 삽입|
|8|AI 흔적 제거|"부사+형용사+가능성 표현+추상 명사" 조합 문장 0건. 발견 시 문장 전체를 재구성|
|9|도구 서술 중립성|특정 도구 홍보·폄하 표현 0건. "이 작업에 이 도구를 선택한 이유는 \~이다" 형태|
|10|마무리 점검|챕터의 마지막이 요약·정리가 아닌 관점의 재정렬로 끝나는가|

**리라이팅 작업 순서:**

1. 체크리스트 10항목을 위에서 아래로 순서대로 적용
2. 항목별로 해당 문장/문단을 찾아 수정
3. 전체 원고를 처음부터 끝까지 소리 내어 읽듯이 통독 (리듬 최종 확인)
4. 리라이팅 변경 내역을 표로 정리 (항목별 수정 건수, 주요 변경 예시)

## Phase 4: 퇴고 3 Pass

### Pass 1: 구조 편집

|#|점검 항목|
|-|-|
|1|전체 서사 아크가 처음부터 끝까지 흐르는가 (도입 → 시행착오 → 체계 구축 → 성찰)|
|2|각 챕터가 장면→맥락→원칙 구조를 따르는가|
|3|파트 간 페이싱이 균형 잡혀 있는가|
|4|서문의 훅이 독자를 끌어당기는가|
|5|에필로그가 서문과 호응하는가|
|6|각 챕터의 첫 문장이 장면(시간·장소·행동)으로 시작하는가|
|7|도구 기능 설명이 경험 서사를 압도하는 챕터가 없는가|
|8|교훈 강요 문장("\~해야 한다", "\~이 중요하다")이 남아 있는가|
|9|중복 에피소드가 없는가|

### Pass 2: 문장 편집

|#|점검 항목|
|-|-|
|1|문장이 30\~60자 범위 안에 있는가|
|2|종결어미가 전체 원고에서 일관되는가|
|3|과장 형용사, 모호 부사, 추측 표현이 없는가|
|4|감정 형용사가 상태 진단형으로 대체되었는가|
|5|문단 간 전환이 자연스러운가|
|6|전문 용어가 한글(영문) 병기로 표기되었는가 (해당 시)|
|7|현장 노트와 Before/After의 형식이 일관되는가|
|8|단문과 중문의 리듬 변화가 있는가|
