# 샘플 챕터 — 저자 작성용 양식

이 파일은 Phase 2 목차 확정 후, Phase 3 집필 시작 전에 저자가 직접 작성한다.
작성된 샘플 챕터는 이후 모든 챕터의 **문체·구조·톤 기준점**이 된다.
Claude는 챕터 작성 전 이 파일을 읽고, 저자의 실제 문체와 구조를 파악해 초안에 반영한다.

---

## 작성 방법

1. 아래 양식에 가장 자신 있는 챕터 하나를 직접 쓴다
2. 분량은 2,000~3,000자 수준이면 충분하다 (전체 챕터 분량의 절반 이하)
3. 완성도보다 **저자 본인의 목소리**가 드러나는 것이 중요하다
4. 작성 후 이 파일을 Claude 프로젝트에 업로드한다

---

## 샘플 챕터 양식

```
[샘플 챕터 정보]
■ 챕터 번호/제목:
■ 이 챕터를 샘플로 선택한 이유:

---

[본문]

(여기에 직접 작성)

---

[저자 메모 — 선택 사항]
이 챕터에서 특히 잘 됐다고 생각하는 부분:
Claude에게 유지해줬으면 하는 문체 특징:
Claude가 피해줬으면 하는 표현 방식:
```

---

## 작성 예시 (참고용)

```
[샘플 챕터 정보]
■ 챕터 번호/제목: Ch2. 프롬프트를 100번 고쳐도 안 되던 이유
■ 이 챕터를 샘플로 선택한 이유: 가장 많이 고민한 챕터라 내 목소리가 잘 드러남

---

[본문]

2023년 가을, 강의 교안을 Claude로 초안 잡으려 했다.
프롬프트를 열두 번 고쳤다. 결과물은 매번 비슷했다.

문제는 프롬프트가 아니었다.
내가 무엇을 원하는지 몰랐던 거다.
"좋은 교안"이라는 기준이 내 안에 없었다.

...

---

[저자 메모]
이 챕터에서 특히 잘 됐다고 생각하는 부분: 첫 문장 도입 방식
Claude에게 유지해줬으면 하는 문체 특징: 짧은 문장으로 끊는 리듬
Claude가 피해줬으면 하는 표현 방식: "~라는 것을 깨달았다" 식의 감정 마무리
```

---

## 샘플 챕터가 없는 경우

샘플 챕터를 작성하지 않아도 집필은 가능하다.
이 경우 Claude는 `writing-style-guide.md`와 `chapter-template.md`만을 기준으로 초안을 작성한다.
첫 챕터 완성 후 "이 챕터를 샘플로 지정해줘"라고 입력하면 이후 챕터의 기준점으로 활용할 수 있다.
