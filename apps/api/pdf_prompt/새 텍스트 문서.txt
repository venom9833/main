# 책 표지·삽화 프롬프트 가이드


---

### 1-1. 책 표지 프롬프트 템플릿

```text
책 표지 디자인.

[기본 사양]
비율: 2:3 세로형 (1200×1800px)
용도: 책 표지

[책 정보]
제목: (한글 제목)
부제: (한글 부제)
저자: (저자명)
장르: (장르)

[레이아웃 — 3 단 분할]
상단 ( )%: 제목 타이포 영역
중단 ( )%: 핵심 비주얼 영역
하단 ( )%: 부제·저자명 영역

[비주얼 요소]
주 오브젝트: (구체 대상, 형태 묘사)
보조 오브젝트: (대상 1~2 개)
배경: (단색 / 질감 / 공간 묘사)
장식: 없음

[컬러 팔레트]
주조색: (이름 #헥스) — 적용 위치
강조색: (이름 #헥스) — 적용 위치
보조 조명색: (이름 #헥스) — 적용 위치

[조명·질감]
광원: (방향·종류)
그림자: 최소 / 없음
재질: (무광 / 사실적 / 플랫)

[타이포그래피]
제목 "(한글 제목)"
- 폰트: Noto Sans KR Bold
- 색상: #(헥스)
- 위치: (상단 / 중앙 / 하단)
- 크기: 표지 폭의 ( )%

부제 "(한글 부제)"
- 폰트: Noto Sans KR Regular
- 색상: #(헥스)
- 위치: (제목 아래 / 하단)
- 크기: 제목의 ( )% 크기

저자명 "(저자)"
- 폰트: Noto Sans KR Regular
- 색상: #(헥스)
- 위치: 하단 중앙

[제외 요소]
(진부한 상징, 피할 스타일 명시)
