# 감정 패턴 레퍼런스 — 실전 참조 소설 5편

> 이 파일은 초기 문체 캘리브레이션용 참조 자료다.
> 매 호출마다 포함하지 않는다. 필요 시 수동 참조.

## 황혼의 오작교 (노수민) — 노년 불륜·애틋한 사랑
- **시점**: 제3자(만두가게 주인)가 관찰하는 방식 → 독자가 궁금해하게 만듦
- **장치**: 두 사람이 항상 같은 자리에서 몰래 만남 → 비밀이 주는 긴장감

## 나는 죽고 싶다 (황미영) — 남편 외도·병든 아내
- **반전 장치**: 아내는 남편의 '여자들'이 자기 집에 드나든다는 것을 안다
- **감정의 역설**: 의식이 있는 척 없는 척하며 가족들의 속마음을 엿듣는 장면

## 황혼 (박완서) — 고부갈등·소외된 노인
- **핵심 장치**: 며느리의 호칭 변화(어머니→노인네→할머니)로 시어머니의 소외 가속화

## 액자 (이문자) — 남편 외도 의심·일상의 균열
- **긴장 구조**: 남편이 매일 서재에서 액자를 만지작거리는 반복 장면 → 의심이 쌓임
- **단서 쌓기**: 늦은 귀가, 전화 안 받기, 설명이 바뀌는 패턴

## 잔인한 승부 (김선주) — 위선적 영웅·뒷돈
- **사이다 구조의 역전**: 강경했던 주민 대표가 건설사 접대에서 뒷돈을 받음
- **인물의 이중성**: 연단에서 분노 → 식사 자리에서 무너짐 → 집에서 봉투를 뜯는 3단계
