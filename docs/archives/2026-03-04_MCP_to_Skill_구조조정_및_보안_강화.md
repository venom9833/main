# 2026-03-04_MCP_to_Skill_구조조정_및_보안_강화

## 1. 개요
본 문서는 2026년 3월 4일 진행된 시스템 아키텍처 구조조정 및 보안 강화 조치에 대한 결정 사항을 기록합니다.

## 2. 주요 결정 및 변경 사항
### A. MCP 서버의 스킬(Skill) 전환
*   **배경**: 상시 구동되는 MCP 서버가 너무 많아 AI 컨텍스트(토큰) 소모가 심하고 시스템 부하가 발생함.
*   **조치**: 다음 4개의 MCP 서버 기능을 2개의 독립 스킬(Level 3 Skill)로 전환함.
    1.  `source-harvester-mcp` → `web_content_extraction` 스킬
    2.  `youtube-mcp`, `notebooklm-audio-mcp` → `youtube_operations` 스킬
*   **효과**: 필요한 시점에만 스크립트를 실행함으로써 컨텍스트 효율을 극대화하고, MCP 툴 총합을 100개 미만으로 관리함.

### B. 폴더 구조 현대화 및 보안
*   **`rules/` → `0. rules/`**: 폴더명을 표준화하고, 깃허브 제외 목록(`.gitignore`)에 명시하여 보안을 강화함.
*   **문서 분리 정책**:
    *   `/0. rules/`: 핵심 행동 지침(코어)만 유지하여 상시 기억하게 함.
    *   `/0. docs/reference_rules/`: PRD, DB 설계서 등 참조용 문서를 이동시켜 컨텍스트 점유를 최소화함.

## 3. 핵심 지시어 업데이트
*   **설계자(Architect) 중심**: 복잡한 수정은 직접 코딩하지 않고 `0. rules/` 내에 `101, 102...` 번호의 설계 문서(SOP)를 작성하여 외부 도구가 실행하게 함.
*   **MCP 가드라인**: 연결된 모든 MCP 도구 합계를 100개 미만으로 엄격히 유지함.

## 4. 향후 과제
*   자동화 파이프라인(`4_content-system`)의 스킬 기반 연동 최적화.
*   남은 참조 문서들의 AI 접근성 테스트 및 활용 가이드 작성.
