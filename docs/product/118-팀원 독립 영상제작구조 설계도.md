# 118 — 팀원 독립 영상제작구조 설계도

> 최종 업데이트: 2026-03-28
> 상태: 아키텍처 확정 / 팀원별 영상제작구조 구축 진행 중

---

## 1. 용어 정의 (전 구성원 필수 숙지)

> AI, 팀원, 코드 주석 모두 아래 용어를 기준으로 통일한다. 혼용 금지.

| 용어 | 정의 |
|------|------|
| **NotebookLM** | Google의 AI 서비스 플랫폼 자체 |
| **노트앱** | NotebookLM 내부에 생성된 개별 노트북 단위 |
| **고정 노트앱** | 팀원의 영상주제 전용으로 운영하는 노트앱. 팀원마다 1개씩 독립 보유 |
| **소스** | 노트앱 안에 등록된 자료 (SRT, URL, PDF, 텍스트 등) |
| **쿼리** | 노트앱에 질문 또는 생성 요청을 보내는 행위 |
| **SRT** | 영상 자막 파일 (.srt 또는 .txt 모두 허용) |
| **영상제작구조** | 팀원 1명이 소유하는 독립 단위 (영상주제 + 화풍 + 로직 + 노트앱의 조합) |
| **화풍** | 키프레임 이미지의 시각 스타일 (예: 지브리 실사풍, 픽사 3D 등) |
| **아이디어** | 쿼리 결과로 생성된 영상 제목 후보 (20개) |
| **대본** | 아이디어 1개 선택 후 생성되는 [씬N] 구조의 영상 스크립트 |
| **OH** | 팀원 한 명의 전용 페이지를 통칭하는 이름 |

## 2. 역할 구분

| 역할 | 담당 | 작업 공간 |
|------|------|----------|
| **통합 환경 개발자** | 팀 리더(나) | `/content/*` — 팀원이 사용할 공통 인프라 구축 |
| **팀원** | 각 팀원 | `/team/*` — 자신의 영상제작구조를 독립 운영 |

> 팀원은 통합 환경(`/content/*`)의 내부 로직을 수정하지 않는다.
> 팀원은 자신의 전용 페이지(`/team/이름-N`)에서만 작업한다.

## 4. 팀원 체크리스트

> 팀원은 개발 시작 전 아래 항목을 확정하고 팀 리더에게 공유한다.

```
□ 1. 영상주제 확정    — 내가 만들 영상의 주제 (예: 동화, 건강, 기술 등)
□ 2. 화풍 확정        — keyframe_style.json 에서 1개 선택
□ 3. 고정 노트앱 생성 — NotebookLM에서 나만의 노트앱 1개 생성
□ 4. 소스 적재        — 내 영상주제에 맞는 자료를 노트앱에 등록
□ 5. 노트앱 ID 공유   — 생성된 노트앱 ID를 3번 표에 기입
□ 6. Git 브랜치 확인  — 배정된 branch(1~5) checkout
□ 7. 전용 페이지 개발 — /team/이름-1 페이지에서 로직 구현 시작
```

## 5. 노트앱 운영 원칙 (전 팀원 공통)

- 노트앱은 팀원마다 1개씩 독립 운영한다
- 소스는 **누적 적재만** 한다 — 삭제 금지
- 노트앱에는 **자신의 영상주제와 관련된 소스만** 적재한다
- 주제가 같은 카테고리라면 세부 주제가 달라도 무방하다
- 주제와 무관한 소스가 섞이면 쿼리 결과가 오염된다

**SRT의 역할**

```
❌ 잘못된 방식: SRT → 노트앱 소스로 주입
✅ 올바른 방식: SRT → 쿼리 프롬프트의 컨텍스트(힌트)로만 전달
```

SRT는 "이번 영상의 주제와 맥락"을 쿼리에 알려주는 힌트다.
실제 대본 내용은 노트앱의 지식 베이스가 생산한다.

## 6. 영상제작구조 흐름 (팀원 공통 기준)

```
[입력]
  유튜브 URL 또는 SRT/TXT 파일
        ↓
[Step 1] 채널/영상 분석
  - 노트앱 쿼리 → 틈새시장 / 타겟 / 제목패턴 / 훅 분석
        ↓
[Step 2] 아이디어 20개 생성
  - 노트앱 쿼리 (SRT 컨텍스트 포함) → 영상 제목 후보 20개
        ↓
[Step 3] 아이디어 1개 선택
        ↓
[Step 4] 대본 생성
  - 노트앱 쿼리 → [씬N] 구조 완성형 대본
        ↓
[출력]
  완성형 대본 → 각 팀원의 다음 단계 페이지로 이동
  (oh-1 완료 → oh-2 / park-1 완료 → park-2)
```

## 8. 팀원 영상제작구조 — 공통 vs 커스텀

### 공통 로직 (약 90%)

팀원은 통합 환경에서 이미 만들어진  로직을 참조해서 개발을한다.

```
대본 생성 → 아이디어 선택 → 씬 구성 → 키프레임 이미지 → 성우 더빙 → 영상 합성
```

### 커스텀 영역 (약 10%) — 팀원마다 다를 수 있는 부분

| 항목 | 기본값 | 커스텀 가능 여부 |
|------|--------|----------------|
| 영상주제 | 경제학 | ✅ 팀원 고유 주제 |
| 화풍 | 1종 고정 | ✅ 팀원 고유 화풍 |
| 노트앱 소스 | 미정 | ✅ 팀원 주제 자료 |
| 캐릭터 사용 여부 | 미사용 | ✅ 사용 or 미사용 선택 |
| 나레이션 성우 수 | 1명 | ✅ 1명 / 2~3명 동시 사용 선택 |
| 대본 톤/스타일 | 경제 정보형 | ✅ 동화·감성·정보·뉴스 등 |

> 커스텀 항목이 늘어나면 이 표에 추가한다.
> 공통 로직은 통합 개발자가 관리하며 팀원이 직접 수정하지 않는다.

## 9. 향후 방향 (검토 중)

> ⚠️ 확정된 방향이 아님. 가설 수준으로 기록.

**고정 노트앱 × 화풍 1:1 세트 구조**
각 팀원의 영상제작구조가 완성된 후, 구조 간 유사성에 따라 공통 컴포넌트 통합 여부를 판단한다.
통합은 완성 이후에 결정한다. 개발 단계에서는 각자 독립적으로 완성하는 것이 우선이다.

**`/content/longform` 과의 관계**
`/content/longform`의 "지식템플릿-화풍 조합 선택" 구조가 팀원에게 1개씩 고정 할당되는 구조로 발전할 수 있다.
최종 방향은 추후 결정.
