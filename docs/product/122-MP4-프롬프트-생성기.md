# 122 — MP4 프롬프트 생성기

> 경로: `/content/mp4-prompt-generator`
> 최종 업데이트: 2026-03-28
> 상태: 구현 완료

---

## 1. 페이지 목표

좋은 이미지를 갖고 있어도 **낮은 품질의 프롬프트**로 인해 낮은 품질의 영상이 생산되는 문제를 해결한다.
사용자에게 Kling AI 등 이미지→영상 도구에 투입할 **고품질 프롬프트**를 제공하는 것이 핵심 목표.
이 페이지의 주 사용 시나리오는 **오프닝 후크 영상** 제작이다.

---

## 2. 구현 구조

```
[후크 강도] + [캐릭터 묘사(선택)] + [캐릭터 행동 or 환경 모션] + [사용자 입력]
+ [기본 프롬프트] + [카메라 이동] + [속도]
+ 네거티브 프롬프트 (다중 선택, 별도 복사)
```

### 레이아웃

3컬럼 고정 (max-w-[1160px]):
- **LEFT (300px)**: 이미지 업로드 + 캐릭터 묘사(조건부) + 씬 설명 + AI 분석 첨가 버튼
- **CENTER (380px)**: 씬 유형 토글 + 후크 강도 + 행동/모션 + 카메라 + 속도 + 네거티브
- **RIGHT (flex-1)**: 영상 제작 프롬프트(검정 배경) + 한글 설명 + 네거티브 카드 + 도구 링크

---

## 3. 프롬프트 구성 요소 및 색상

| 구성 요소 | 색상 | 설명 |
|----------|------|------|
| 후크 강도 | orange(주황) | 프롬프트 최상단 삽입. 없음/시각충격/긴장감/드라마틱/미스터리 5종 |
| 캐릭터 묘사 | sky(파랑) | 주요 캐릭터 있음 모드에서만 표시 |
| 캐릭터 행동 | pink(분홍) | 호흡/시선이동/걷기 등 8종 |
| 환경 모션 | teal(청록) | 나뭇잎/수면/구름 등 8종 (캐릭터 없음 모드) |
| 사용자 입력 | violet(보라) | 자유 입력, 기본 프롬프트 위에 위치 |
| 기본 프롬프트 | green(초록) | 키프레임 IDB 자동 로드 |
| 카메라 이동 | indigo(남색) | 단일 선택 |
| 속도 | amber(노랑) | 단일 선택 |
| 네거티브 | red(빨강) | 다중 선택 11종, 별도 카드 + 독립 복사 |

---

## 4. 씬 유형 모드

| 모드 | 기본값 | 프롬프트 우선순위 | 카메라/속도 |
|------|--------|----------------|------------|
| 주요 캐릭터 없음 | ✅ | 후크→사용자→환경모션→기본→카메라+속도 | 공간·배경 중심 카메라 / 카메라 이동 속도 |
| 주요 캐릭터 있음 | — | 후크→캐릭터묘사→캐릭터행동→사용자→기본→카메라+속도 | 피사체를 향한 카메라 / 캐릭터 동작 속도 |

---

## 5. IDB 연동

- `ld_keyframe` DB → `state` 스토어
- `nl_edits[0]` (1순위): 사용자가 키프레임에서 직접 편집한 씬1 프롬프트
- `translated_scenes[0]` (2순위): Gemini 번역 결과 씬1 비주얼 키워드
- `keyframe_data.scenes[0]`: 한글 원본 씬 텍스트 (한글 설명 카드에 표시)

페이지 진입 시 자동 로드 → **기본 프롬프트는 채워진 상태**, 씬 설명 textarea는 빈 상태 유지.

---

## 6. AI 분석 첨가 기능

- 위치: LEFT 패널 하단 버튼
- 동작: 업로드 이미지(선택) + 한글 캐릭터 묘사 + 한글 씬 설명 → Gemini 2.5 Flash → 영문 키워드 자동 변환
- 결과: `charInput`(캐릭터 묘사 영문화), `baseInput`(씬 설명 영문화) 자동 입력
- API Key: `localStorage.getItem('ld_google_api_key')` 사용
- **비용 주의**: 이미지 포함 시 Gemini 입력 토큰 대량 소모 (이미지 1장 = 최대 2,688 토큰)
- 툴팁: "API 사용으로 비용이 발생됩니다"

---

## 7. 프롬프트 출력 영역

- 배경: `bg-gray-950` (검정)
- 각 구성 요소별 색상 코딩으로 출처 구분
- 하단 한글 설명 카드: 카메라 이동 desc + 속도 desc + koScene 표시
- 복사 버튼: 영상 제작 프롬프트 / 네거티브 프롬프트 각각 독립 복사

---

## 8. 프롬프트 품질 주의사항

한글이 프롬프트에 포함되면 Kling이 해당 키워드를 무시하거나 오해석한다.
→ **반드시 AI 분석 첨가 버튼으로 영문 변환 후 사용 권장**

카메라 지시 충돌 금지 (예: `crash zoom` + `slow push-in` 동시 사용 → 한 가지만 선택)
