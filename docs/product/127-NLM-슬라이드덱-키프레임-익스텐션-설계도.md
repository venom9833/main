## 1. 핵심 판단 근거

### 왜 NLM slide_deck인가
- NLM은 슬라이드 생성 시 **화풍을 내부적으로 렌더링**한다
- `focus_prompt`에 "일본 애니메이션 스타일, 텍스트 없음" 입력 → NLM이 해당 화풍으로 시각화
- 외부 이미지 생성 AI(Gemini, Flux 등) 없이 NLM 자체 품질로 40장 확보 가능
- 실제 성공 프롬프트 확인됨 (영상 제작자 검증)

### 왜 완전 자동화가 가능한가

영상 제작자가 수동으로 한 "메모 저장 → 소스 변환" 동작을  
`source_add(type="text")`로 API에서 직접 대체 가능 — UI 개입 구간 전부 소멸

```
이전 판단: 자동(4) → 익스텐션 가이드(5) → 자동(4)
확정 설계: 전구간 자동 — 사용자 개입 0회
```

### 화풍 제어 방식 확정
- `visual_style_code`는 Video Overview 전용 (slide_deck에 없음)
- slide_deck 화풍은 `focus_prompt` 텍스트로 지정 → 영상 제작자 성공으로 동작 검증됨
- **내장된 NLM 화풍에 한해서만 동작** — 완전 새로운 화풍 강제 주입은 불확실

## 3. 핵심 코드 구조

```python
# apps/api/services/keyframe/pipeline.py

class KeyframePipeline:

    async def run(self, job: KeyframeJob):
        # STEP 1~2: Claude API
        story = await claude.generate_story(job.world)
        characters = await claude.generate_characters(job.world)

        # STEP 3: NLM 소스 추가
        nlm.add_source(notebook_id, type="text", text=story, title="스토리")
        nlm.add_source(notebook_id, type="text", text=characters, title="캐릭터 시트")

        # STEP 4: 40개 프롬프트 생성
        response = nlm.notebook_query(notebook_id,
            "스토리와 캐릭터를 기반으로 40개 장면으로 나눠 "
            "각 장면의 이미지 프롬프트를 한국어로 번호를 붙여 작성해줘")

        # STEP 5: 프롬프트 소스로 직접 추가 (UI 불필요)
        nlm.add_source(notebook_id, type="text",
            text=response.text, title="키프레임 프롬프트 40개")

        # STEP 6~7: 슬라이드 덱 생성 (병렬)
        STYLE = "슬라이드에는 텍스트를 넣지 말아줘. 슬라이드 스타일은 일본 애니메이션 스타일로 해줘."
        aid1 = nlm.create_slide_deck(notebook_id,
            focus_prompt=f"1번부터 20번까지의 프롬프트를 시각화해서 슬라이드를 만들어줘. "
                         f"애니메이션으로 만들 수 있도록 각각의 슬라이드가 키프레임이 되도록 해주고, {STYLE}",
            language="ko")
        aid2 = nlm.create_slide_deck(notebook_id,
            focus_prompt=f"21번부터 40번까지의 프롬프트를 시각화해서 슬라이드를 만들어줘. "
                         f"애니메이션으로 만들 수 있도록 각각의 슬라이드가 키프레임이 되도록 해주고, {STYLE}",
            language="ko")

        # STEP 8: 완료 대기 → 다운로드
        await self._poll_until_done([aid1, aid2])
        pdf1 = nlm.download_artifact(aid1)  # slides_1-20.pdf
        pdf2 = nlm.download_artifact(aid2)  # slides_21-40.pdf

        # STEP 9: PDF → PNG
        frames = pymupdf_to_png(pdf1) + pymupdf_to_png(pdf2)  # 40장

        # STEP 10~12: 대사 → TTS → FFmpeg
        dialogues = await self._generate_dialogues(notebook_id)
        audios = await edge_tts.batch(dialogues)
        await ffmpeg.assemble(frames, audios)
```

## 9. 리스크 및 대응

| 리스크 | 가능성 | 대응 |
|--------|--------|------|
| NLM slide_deck 화풍 품질 불만족 | 중간 | Phase 1 검증 후 진행 여부 결정 |
| focus_prompt 화풍 지시 무시 | 중간 | 여러 화풍 프리셋 테스트 → 실제 동작하는 것만 채택 |
