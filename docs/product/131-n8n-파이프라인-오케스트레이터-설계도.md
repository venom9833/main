## 1. 핵심 철학

> "파이프라인 순서 제어는 n8n이, 비즈니스 로직은 FastAPI가."

현재 bat 파일 + `orchestrator.py` 수동 실행 구조를 n8n 스케줄러로 대체한다.  
FastAPI 서비스 레이어는 건드리지 않고, n8n은 HTTP 호출 오케스트레이터 역할만 한다.

## 3. 도입 범위

### 도입 적합 구간

| 현재 구현 | n8n 대체 효과 |
|---|---|
| bat 파일 수동 실행 | Schedule Trigger → 완전 자동 |
| `skill-4-telegram-bot` | Telegram Node 내장, 코드 불필요 |
| 파이프라인 실행 이력 없음 | 모든 실행 기록 UI에서 확인 가능 |
| 실패 알림 없음 | Error Trigger → Telegram 자동 알림 |

### 도입 불필요 구간

| 구간 | 이유 |
|---|---|
| FFmpeg 영상 합성 | 바이너리/대용량, FastAPI 직접 처리 유지 |
| edge-tts TTS 생성 | 로컬 프로세스, FastAPI 래핑 유지 |
| Gemini 이미지 생성 | raw bytes 처리, Python SDK 직접 사용 |
| 대본 파싱 / 씬 분할 | 복잡한 비즈니스 로직, Python 유지보수 편함 |

## 4. 파이프라인 설계

### 메인 워크플로우 (일일 자동 실행)

```
Schedule Trigger (매일 07:00)
  │
  ├─ HTTP POST /api/trends/collect       ← 트랜드 수집 (YouTube, 네이버 등)
  │
  ├─ HTTP POST /api/series/generate      ← 대본 생성 (Gemini + NLM)
  │
  ├─ HTTP POST /api/tts/batch            ← TTS 생성 (edge-tts)
  │
  ├─ HTTP POST /api/video/render         ← 영상 합성 (FFmpeg)
  │
  └─ Telegram Node "완료 알림"
```

### 에러 워크플로우

```
Error Trigger (메인 워크플로우 실패 시)
  │
  └─ Telegram Node "실패 알림 + 에러 상세 + 실패 노드명"
```

### 단순 대체 후보 (FastAPI 없이 n8n만으로 구성 가능)

```
Schedule Trigger
  → YouTube Node (트랜드 키워드 검색)
  → Supabase Node (결과 저장)
  → Telegram Node "수집 완료"
```

---

## 5. FastAPI 엔드포인트 요구사항

n8n HTTP Request 노드가 호출할 엔드포인트는 다음 원칙을 따른다:

- 모든 엔드포인트 → JSON 응답 (status, message, result)
- 성공: HTTP 200, 실패: HTTP 4xx/5xx (n8n Error Trigger 동작 조건)
- 장기 실행 작업 → 비동기 Job ID 반환 + 별도 polling 엔드포인트 제공

## 6. 설치 방법 (Docker)

```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n
```

접속: `http://localhost:5678`

## 7. 통합 노드 목록 (LinkDrop 관련)

| 노드 | 용도 |
|---|---|
| Schedule Trigger | 매일 정해진 시간 자동 실행 |
| HTTP Request | FastAPI 엔드포인트 호출 |
| YouTube | YouTube Data API v3 트랜드 검색 |
| Supabase | DB insert/select/upsert |
| Telegram | 완료/실패 알림 |
| Code (JS) | 간단한 데이터 가공 |
| IF / Switch | 조건 분기 (실패 클립 재시도 등) |
| Error Trigger | 실패 감지 → 복구 워크플로우 연결 |

## 8. 구현 순서 (착수 시)

1. Docker로 n8n 로컬 설치 확인
2. 메인 워크플로우 Schedule Trigger + HTTP Request 노드 구성
3. Error Trigger + Telegram 알림 연결
4. `skill-4-telegram-bot` 코드 제거 (n8n으로 이전)
5. `orchestrator.py` / bat 파일 제거 (n8n으로 이전)
6. YouTube 트랜드 수집 → n8n YouTube Node + Supabase Node 대체 검토

---

## 9. 보안 주의사항

- **CVE-2025-68668**: Python Code 노드 임의 명령어 실행 취약점 → n8n v2.0.0 이상 사용 필수
- n8n 인스턴스는 외부 노출 금지 (로컬 전용 또는 VPN 내부)
- `.env`의 API 키는 n8n Credentials 기능으로 관리 (코드에 하드코딩 금지)
