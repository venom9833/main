# 📋 03. 문서 출력 언어 표준

## 1. 원칙
- LinkDropV2 레포지토리 내 문서(`docs/**`)는 기본적으로 한글로 작성한다.
- 도구/라이브러리 명칭, 코드 식별자, URL/경로 등 고유명사는 원문을 유지한다.

## 2. 필수 섹션 표기
- “AGENT Review Summary”는 문서에서 “에이전트 검토 요약”으로 표기한다.
- 같은 의미의 영어 섹션 타이틀이 존재하면 한글 타이틀을 우선 표기한다.

## 3. 예외
- 외부 공유/제출용으로 영문 문서가 반드시 필요할 경우, `docs/archives/`에 별도 파일로 분리하고 파일명에 `_en`을 포함한다.
