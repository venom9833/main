# fieldnote-book-workflow — 챕터 구조 템플릿

이 파일은 모든 챕터의 내부 구조 기준이다.
Phase 3 초안 작성 전 반드시 읽는다. 구조는 변경하지 않는다.

---

## 챕터 내부 구조: 장면 → 맥락 → 원칙

모든 챕터는 세 덩어리로 구성된다.

### ① 장면 (Scene) — 챕터의 30%

구체적 상황으로 시작한다. 날짜, 도구, 작업 내용이 보이는 현장 묘사.
독자가 "나도 이런 적 있다"고 느끼는 진입점.

**작성 기준:**
- 첫 문장은 시간·장소·행동 중 하나로 시작한다 (개념이나 정의로 시작하지 않는다)
- 구체적 디테일을 포함한다: 도구명, 작업 내용, 걸린 시간, 화면에 보인 것
- 1~3개 에피소드를 병렬로 배치하거나, 하나의 에피소드를 깊게 풀 수 있다
- 원재료(블로그, 매거진 등)에서 가져온 경험은 자연스럽게 녹인다 (출처를 밝히지 않는다)

**예시 톤:**
> 세 번째 강의를 마치고 나서야 문제를 알아챘다. 준비한 내용은 충분했지만, 수강생이 어디서 막히는지를 보지 못했다. 그때부터 강의 설계 방식을 바꿨다.

---

### ② 맥락 (Context) — 챕터의 40%

왜 그런 선택을 했는지, 무엇이 문제였는지 설명한다.
저자의 경험에서 나온 비교("예전에는 이랬는데 지금은 이렇다")가 여기서 작동한다.

**작성 기준:**
- 장면에서 드러난 문제를 명확히 정의한다
- 방법론 변경 전/후, 도구 도입 전/후 비교를 포함한다
- 독자가 공감할 수 있는 구체적 맥락을 제공한다
- 저자의 현장 경험(강의, 프로젝트, 집필 등)을 자연스럽게 연결한다
- 기능 설명이나 도구 조작법은 최소화한다. 필요하면 현장 노트 박스로 분리한다

---

### ③ 원칙 (Principle) — 챕터의 30%

경험에서 뽑아낸 판단 기준 1~3개.
"이럴 때는 이렇게 한다"는 짧은 문장으로 정리한다.

**작성 기준:**
- 원칙은 독자가 자기 상황에 옮겨 쓸 수 있는 형태여야 한다
- 추상적 교훈이 아니라 실행 가능한 판단 기준으로 제시한다
- 원칙 제시 후 "단, ~인 경우에는" 형태의 예외 조건을 붙인다
- 챕터의 마지막은 요약이 아니라 관점의 재정렬로 마무리한다

---

## 보조 장치

본문 사이에 두 가지 보조 장치를 배치한다. 챕터당 1~3개.

### 현장 노트 (Field Note)

저자의 실제 작업 기록, 메모, 판단의 순간을 짧게 삽입한다. 200~400자.

**형식:**
```
[현장 노트] 날짜 또는 시점, 상황
내용. 날것의 기록으로 남긴다. 결론이나 교훈을 쓰지 않는다.
```

**규칙:**
- 날짜와 상황을 반드시 포함한다
- 결론이나 교훈을 쓰지 않는다. 날것의 기록으로 남긴다
- 원재료(블로그, 매거진 등)의 호수나 회차를 직접 언급해도 된다

---

### Before/After 비교

방법론 변경 전후, 도구 도입 전후의 작업 결과물이나 프로세스를 병렬로 보여준다.

**형식:**
```
[Before] 시점 또는 상황
- 항목: 내용

[After] 시점 또는 상황
- 항목: 내용
- 단, ~인 점은 오히려 늘었다/달라졌다. (비교에서 드러나는 판단 포인트)
```

**규칙:**
- 수치나 구체적 사실을 포함한다
- 단순 비교가 아니라, 비교에서 드러나는 판단 포인트를 한 문장 덧붙인다

## 샘플 챕터 (저자 작성)

> **Claude에게:** 이 섹션은 저자가 직접 작성한 샘플 챕터다. 아래 내용이 채워져 있으면 Phase 3 모든 챕터 작성 전 반드시 읽고, 저자의 실제 문체·구조·톤을 파악해 초안에 반영한다. 비어 있으면 위의 구조 기준만 적용한다.

### 작성 방법 (저자 참고)

Phase 2 목차 확정 후, Phase 3 시작 전에 아래 양식을 채운다.
가장 자신 있는 챕터 하나를 2,000~3,000자 수준으로 직접 쓴다.
완성도보다 **본인의 목소리**가 드러나는 것이 중요하다.

```
[샘플 챕터 정보]
■ 챕터 번호/제목:
■ 이 챕터를 샘플로 선택한 이유:

---

[본문]

(여기에 직접 작성)

---

[저자 메모 — 선택 사항]
잘 됐다고 생각하는 부분:
Claude가 유지해줬으면 하는 문체 특징:
Claude가 피해줬으면 하는 표현 방식:
```

### 샘플이 없는 경우

샘플 챕터 없이 집필해도 된다.
이 경우 Claude는 위 구조 기준과 `writing-style-guide.md`만 적용해 초안을 작성한다.
첫 챕터 완성 후 "이 챕터를 샘플로 지정해줘"라고 입력하면 이후 챕터의 기준점으로 활용한다.
